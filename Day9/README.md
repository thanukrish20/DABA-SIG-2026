# Day 9 - Response Quality and Issue Detection

## Objective
Identify unsafe, unsupported, and irrelevant responses generated by the assistant.

## Implementation
- Created test cases with different journal entries and responses.
- Developed keyword-based rules to identify problematic responses.
- Compared expected issues with detected issues.
- Classified test results as Pass or Review.
- Generated a summary of detected issue types.

## Issue Categories
- **Unsafe:** Responses that disregard safety concerns.
- **Unsupported:** Responses that make assumptions without sufficient evidence.
- **Irrelevant:** Responses unrelated to the journal entry.

## Tools Used
- Python
- Pandas
- Google Colab

## Limitation
The current approach uses predefined keywords and phrases. It may miss new or indirectly expressed issues, so flagged and unflagged responses may require human review.
