# Day 6 – Guarded Mood-Journal Assistant

## Objective
Develop a mood-journal assistant that analyzes text, selects supportive responses, and applies basic safety guardrails.

## Tasks Completed
- Created a mood sentiment analysis function.
- Implemented basic keyword-based safety screening.
- Combined mood analysis and safety checks.
- Designed supportive responses for different sentiment categories.
- Tested positive, negative, neutral, and safety-related journal entries.
- Added interactive journal input.
- Generated a project summary.

## Technologies Used
- Python
- TextBlob
- Google Colab

## Status
Day 6 implementation completed.

## Limitations
Sentiment analysis may misinterpret journal text. Keyword screening cannot reliably identify every safety concern. The assistant provides general supportive messages and is not a mental-health diagnostic tool or a substitute for professional support.
