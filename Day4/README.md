# Day 4 – Safe-Support Knowledge Base and Safety Rules

## Objective
Build a safe-support knowledge base and define basic safety rules for the AI User Retention and Mood Analyzer.

## Tasks Completed
- Created a support knowledge base with categories and messages.
- Defined basic keyword-based safety rules.
- Prioritized safety-related responses over regular mood responses.
- Connected the knowledge base with sentiment analysis.
- Tested positive, negative, and safety-keyword scenarios.
- Generated a safety report.

## Technologies Used
- Python
- Pandas
- TextBlob
- Google Colab

## Status
Day 4 implementation completed.

## Limitations
Keyword screening can miss important context and does not independently assess a person's safety. Sentiment analysis is an approximate text-based signal, not a mental-health diagnosis. The support messages are general guidance and do not replace professional help.
