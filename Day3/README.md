# Day 3 – Integrated Retention and Mood Analyzer

## Objective
Connect app usage patterns with journal sentiment insights while maintaining basic safety guardrails.

## Tasks Completed
- Combined app usage data and journal entries in one dataset.
- Calculated sentiment scores using TextBlob.
- Classified journal entries as Positive, Negative, or Neutral.
- Connected usage patterns with mood insights.
- Added basic keyword-based safety screening.
- Generated an integrated user report.
- Summarized the analysis for multiple sample users.

## Technologies Used
- Python
- Pandas
- TextBlob
- Google Colab

## Status
Day 3 implementation completed.

## Limitation
This project uses sample data and basic sentiment analysis. The results are illustrative, not diagnostic. Keyword screening is limited and cannot independently determine a person's safety.
