# Day 11 - Guarded Journal Interface

## Objective
Develop an interactive journal interface with mood analysis and basic safety guardrails.

## Implementation
- Created a journal text box using IPyWidgets.
- Added an Analyze Journal button.
- Connected the interface to mood analysis.
- Implemented empty-input validation.
- Added keyword-based safety checking.
- Displayed supportive responses based on detected text sentiment.

## Tools Used
- Python
- Google Colab
- IPyWidgets
- TextBlob

## Testing
- Normal journal entry
- Empty input
- Safety-related keyword input

## Limitation
The keyword-based safety check may miss concerns expressed in other ways. Sentiment analysis cannot reliably determine a person's actual emotional state.
