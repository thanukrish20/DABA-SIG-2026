# Day 12- Integrated Usage Analysis, Journal Processing and Safeguards

## Objective
Integrate app usage analysis, journal sentiment processing, and safety checks into one workflow.

## Implementation
- Created a sample app usage dataset.
- Classified usage as High Usage or Low Usage.
- Analyzed journal entries using TextBlob sentiment analysis.
- Classified journal sentiment as Positive, Neutral, or Negative.
- Added keyword-based safety checks.
- Merged app usage and journal results using a common user ID.
- Generated an integrated user report.
- Validated the combined dataset and checked for missing values.

## Tools Used
- Python
- Pandas
- TextBlob
- Google Colab

## Output
The integrated report displays app usage details, detected mood, sentiment score, and safety status for each sample user.

## Limitations
The project uses sample data and basic keyword-based safeguards. Sentiment classification and keyword checks may produce incorrect or incomplete results.
