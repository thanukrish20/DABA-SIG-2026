# Day 5 – Safe Journal Prompts and Safety Guardrails

## Objective
Design safe prompts for journal interactions while maintaining safety rules and supportive communication.

## Tasks Completed
- Created prompt templates for Positive, Neutral, Negative, and Safety categories.
- Defined journal interaction safety rules.
- Built a prompt selector using sentiment analysis and basic keyword screening.
- Tested the selector with different journal entries.
- Created an interactive journal input function.
- Generated a project completion summary.

## Technologies Used
- Python
- TextBlob
- Google Colab

## Status
Day 5 implementation completed.

## Limitations
The system selects predefined prompts; it does not generate actual LLM responses. Sentiment analysis may misclassify text, and keyword screening can miss important context. The system is not a mental-health diagnostic tool.
