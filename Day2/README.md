# Day 2 – AI User Retention & Mood Analyzer

## Objective
Analyze app usage patterns, evaluate user retention, and improve mood journal sentiment analysis with basic safety guardrails.

## Tasks Completed
- Created and analyzed an app usage dataset.
- Trained a Random Forest retention model.
- Evaluated model performance using accuracy, classification report, and confusion matrix.
- Analyzed feature importance.
- Classified journal entries as Positive, Negative, or Neutral.
- Compared journal sentiment scores to detect negative shifts.
- Added a basic keyword-based safety guardrail.
- Combined sentiment analysis and safety screening.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TextBlob
- Matplotlib
- Google Colab

## Status
Day 2 implementation completed.

**Note:** The dataset is small and illustrative. Model accuracy and sentiment scores require validation with appropriate real-world data. Keyword screening is limited and cannot independently assess a person's safety.
