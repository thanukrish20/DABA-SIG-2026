# Day 10 - Improved Safety Prompts and Guardrails

## Objective
Improve the safety prompts and guardrails of the mood-journal assistant.

## Implementation
- Created safety rules for respectful and supportive responses.
- Designed prompts for positive, neutral, negative, safety-related, and empty inputs.
- Implemented keyword-based safety detection.
- Integrated safety checks with mood analysis.
- Tested different journal inputs and verified guardrail behavior.

## Safety Features
- Prioritizes safety-related concerns.
- Encourages contacting a trusted person or qualified professional.
- Avoids judgment and unsupported assumptions.
- Handles empty journal entries.

## Tools Used
- Python
- TextBlob
- Google Colab

## Limitation
Keyword-based detection can miss safety concerns expressed in different words. Sentiment analysis does not diagnose emotions or mental-health conditions.
