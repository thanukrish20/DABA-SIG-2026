# Day 8 - Response Relevance and Safety Evaluation

## Objective
Evaluate the relevance of mood-journal responses and check basic safety compliance.

## Implementation
- Created positive, neutral, negative, and empty-input test cases.
- Implemented a guarded mood-journal assistant.
- Checked whether responses match the expected mood.
- Evaluated basic safety compliance.
- Calculated passed and failed test counts.

## Tools Used
- Python
- Pandas
- TextBlob
- Google Colab

## Limitation
The evaluation uses simple rule-based checks. It cannot guarantee complete safety or accurately interpret every journal entry.
